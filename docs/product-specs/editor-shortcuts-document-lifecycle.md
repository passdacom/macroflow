# 키/단축키 작성과 에디터 문서 수명주기 (v1.10.0)

## 사용자 동작
- 앱은 마지막 파일을 자동으로 열지 않고, 빈 **새 매크로**로 시작한다. 창 배치 등 일반 설정은 유지한다.
- 에디터의 **키 / 단축키 추가**에서 복사(Ctrl+C), 붙여넣기(Ctrl+V), 클립보드 기록(Win+V), Esc 등 프리셋을 선택한다.
- 직접 지정은 Ctrl/Alt/Shift/Win과 키 이름 목록으로 구성한다. 물리 키 조합을 캡처하지 않으며 작성 중 실제 입력을 보내지 않는다.
- 선택 행 다음(선택이 없으면 끝)에 RAW key_down들과 역순 key_up들을 추가한다. 전체 삽입은 한 번의 Undo로 취소한다. 원본 raw_events는 변경하지 않는다.
- 실행 전 대기의 기본값은 기존 삽입 UX와 같은 1000ms이며 조절 가능하다. 키 유지 시간은 매크로 시간 기준 100ms, 재생 속도 영향을 받는다.
- Ctrl+V는 재생 시점의 클립보드를 붙여넣는 키 동작이다. 저장된 문자열을 넣는 **텍스트 입력 추가**와 구분한다.
- Win+V는 Windows 클립보드 기록 UI를 여는 키 동작이다. 기록 기능 활성화/권한/대상 환경은 Windows 설정에 따른다.

## 파일·녹화·복원
- 새 녹화 시작이 성공하면 이전 파일 경로와 분리된 새 문서로 전환한다. 저장은 새 파일 저장 창을 사용한다.
- native 녹화 시작 실패 시 현재 문서와 기존 복원 지점은 유지한다.
- 새 녹화 직전의 매크로 내용·파일 경로·저장 기준 snapshot을 보관한다. **이전 복원**은 세 가지를 함께 복원하므로 기존 파일의 미저장 편집도 보존한다.
- **원본 복원**(에디터의 raw_events 복원)은 현재 매크로의 녹화 원본을 되살리는 기존 기능이다. 녹화 전 문서 복원과 구분한다.
- **이어서 녹화**는 기존 파일 연결을 유지하며 새 이벤트를 추가한다.
- 미저장 변경은 제목/탭의 `*`로 표시한다. 파일 열기·병합 결과 적용·이전 복원·종료 시 저장/버리기/취소로 보호한다.
- 새 녹화는 전용 복원 snapshot과 녹화 전 백업을 사용하는 교체 경로다.
- 저장 실패/취소 시 내용과 파일 경로·dirty 상태를 유지한다. 같은 파일을 다시 열며 Save를 선택한 경우 저장한 새 바이트를 다시 읽는다.
- 실행 중 또는 문서 확인 dialog 소유 중에는 문서 교체/저장을 차단한다.

## 포함한 안정성 수정
- pause와 native 입력 경계 동기화: 이벤트 누락이나 거짓 진행률 없이 resume 후 실행.
- 부분 붙여넣기 실패 시 수락된 prefix가 소유한 키만 release-only로 정리. 붙여넣기를 재전송하지 않는다. OS가 해제를 거부하면 로그로 남기는 bounded best effort다.
- 이미 열린 마우스 제스처를 닫을 때 down을 다시 주입하지 않는다.
- 데이터 이전 충돌 이름을 즐겨찾기 인덱스 최초 복사에도 적용한다.
- 손상 인덱스는 구조 검증하고 원본 바이트 백업 성공 전에 교체하지 않는다.
